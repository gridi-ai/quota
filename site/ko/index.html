한도는 한곳에서.

01 / 여러 계정터미널 로그인은 그대로.

Codex는 계정마다 별도 프로필을, Claude는 별도 인증을 사용합니다. 기존 CLI 로그인을 바꾸지 않으며, 서로 다른 계정의 퍼센트를 평균내지 않습니다.

02 / 남은 사용량추정 대신 실제 한도.

Claude의 5시간·주간 한도와 Codex 계정이 반환하는 기간별 한도·초기화 시간을 보여줍니다. 제공되지 않은 한도를 100%라고 추정하지 않습니다.

03 / 로컬 도구작업하는 곳 바로 옆에.

항상 위에 표시, 컴팩트·확장 보기, 메뉴 막대를 지원합니다. 실행 중 5분마다 갱신하며 Quota 서버·분석 추적·구독료·유료 기능 잠금은 없습니다.

무료 프리뷰 설치.

  1. Apple Silicon용 Quota 0.1.1을 다운로드하고 압축을 푼 뒤 Quota.app을 Applications에 넣습니다. Xcode는 필요 없습니다.
  2. 현재 빌드는 Apple 미공증입니다. 차단되면 소스를 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 사용하세요. Gatekeeper를 끌 필요는 없습니다.
  3. 앱에서 계정 추가를 선택합니다. Codex는 공식 Codex CLI가 필요하고 Claude는 브라우저 인증 코드를 사용합니다. 설정에서 한국어·영어를 고를 수 있습니다.

터미널 설치나 Intel Mac을 사용하나요? 검증된 설치 스크립트 또는 소스 빌드를 이용하세요.

Claude 연결 전에 확인하세요. 현재 Claude Code public OAuth client와 문서화되지 않은 사용량 API를 사용하며, Quota가 승인받은 공식 연동이 아닙니다. Anthropic의 인증 규정은 제3자 앱의 Claude.ai 로그인·토큰 처리를 제한합니다. 제공자 변경으로 조회가 중단될 수 있습니다.

정식 유통 전에는 공식 Claude Code status-line 스냅샷 또는 명시적 연동 허용을 검토하도록 제안했습니다. 전환안과 기능 차이 보기.

자주 묻는 질문.

API 비용과 무엇이 다른가요?

Claude·ChatGPT/Codex 구독 계정이 반환하는 남은 한도와 초기화 시간을 보여줍니다. API 비용을 추정하거나, 한도를 구매하거나, 모델을 호출해 사용량을 측정하지 않습니다.

여러 계정도 지원하나요?

네. 계정별 식별자와 마지막 사용량을 분리합니다. Codex는 각각 다른 프로필, Claude는 각각 별도 인증을 사용합니다. 실제 조회는 Codex 두 계정과 Claude 한 계정까지 확인했으며 두 번째 Claude 계정 격리와 전체 토큰 만료 회전은 추가 검증 영역입니다.

브라우저나 CLI를 계속 켜둬야 하나요?

Codex CLI는 필요하며 Quota가 로컬 app-server helper로 실행합니다. 현재 실험적 Claude 연동은 연결 후 브라우저나 Claude CLI를 켜둘 필요가 없습니다. 제안된 공식 status-line 대안은 Claude Code 활동에 의존하므로 비활성 계정을 독립 갱신하지 못합니다.

계정과 인증 정보는 어디에 저장되나요?

Claude 토큰은 계정별 macOS Keychain 항목에, Codex 인증은 지정한 CLI 프로필에 저장합니다. 계정 메타데이터와 마지막 사용량은 Mac에 남습니다. Quota 서버나 분석 추적은 없습니다. 목록에서 제거해도 제공자 권한·인증정보가 삭제되지는 않습니다. 개인정보·연결 해제 안내를 확인하세요.

무료인가요? 커피 후원으로 무엇이 열리나요?

모든 기능이 무료이며 구독료나 계정 수 제한이 없습니다. 개발자에게 커피 사주기는 선택 사항이고 추가 기능을 열지 않습니다. 소스는 MIT 라이선스입니다.

App Store 앱이거나 Apple 공증을 받았나요?

아니요. ad-hoc 서명한 커뮤니티 프리뷰이며 Apple 공증이나 App Store 심사 제출은 하지 않았습니다. 스토어판은 sandbox·helper·제공자 연동 허용을 별도로 검증해야 합니다.
