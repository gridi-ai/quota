01 / AccountsNo CLI account swapping.

Connect separate Codex profiles and Claude authorizations. Quota does not replace your existing terminal login. Account percentages are never averaged together.

02 / Remaining quotaWindows, not guesses.

See the provider's returned limits and reset times: Claude's five-hour and weekly windows, and the windows your Codex account exposes. Missing limits stay unavailable, not 100%.

03 / Local utilityBeside your work.

Pin the window, choose compact or expanded view, or check the menu bar. Refresh runs every five minutes while the app is open. No Quota server, telemetry, subscription or paid feature unlocks.

Install the free preview.

  1. Download Quota 0.1.1 for Apple Silicon, unzip it and move Quota.app into Applications. No Xcode is needed.
  2. This build is not notarized. If macOS blocks it, review the source, then use System Settings → Privacy & Security → Open Anyway. Do not disable Gatekeeper.
  3. Open Quota and choose Add account. Codex needs the official Codex CLI; Claude uses a browser authorization code. Choose English or Korean in Settings.

Prefer Terminal or use an Intel Mac? See the verified installer or source build.

Read before connecting Claude. The current integration uses Claude Code's public OAuth client and undocumented usage endpoints. It is not an approved Quota integration. Anthropic's authentication rules restrict third-party Claude.ai login and token handling. Provider changes can break it.

Before wider distribution, the proposed alternatives are official Claude Code status-line snapshots or explicit provider permission. Read the integration trade-offs.

A few useful answers.

Does Quota track API costs or subscription quota?

Subscription quota: remaining percentages and reset times returned for your Claude or ChatGPT/Codex account. It does not estimate API billing, buy more quota or make model requests to measure usage.

Can I track multiple Claude and Codex accounts?

Yes. Each account has a separate identity and snapshot. Codex uses a distinct profile for each account. Claude uses a separate authorization. Two Codex accounts and one Claude account were live-tested; second-Claude isolation and a complete token-expiry cycle remain extended checks.

Do I need to keep a CLI or browser open?

Codex requires its CLI, which Quota starts as a local app-server helper. The current experimental Claude integration does not require a running browser or Claude CLI after pairing. A future status-line alternative would depend on Claude Code activity and could not independently refresh inactive accounts.

Where are my credentials stored?

Claude tokens use account-specific macOS Keychain entries. Codex owns credentials in each selected profile. Account metadata and last-known quota stay on your Mac. The Mac app has no Quota backend or analytics; this website uses Google Analytics as described below. Removing a row does not revoke provider grants or erase credentials; see the privacy and removal guide.

Is Quota free? What does coffee support unlock?

Every feature is free, with no subscription or account cap. Buying the developer a coffee is optional and unlocks nothing. The source is MIT licensed.

Is this an App Store or notarized release?

No. This is an ad-hoc signed community preview, not Apple-notarized or submitted to the App Store. A store edition would need separate sandbox, helper and service-permission verification.
